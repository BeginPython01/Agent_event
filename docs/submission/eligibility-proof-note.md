# Proof of Eligibility — notes

Each member attaches proof of full-time student status (e.g. MFU student ID card or enrolment certificate).
Documents in Thai need a one-line English note. **Do not commit scans to git** (personal data).

Note template (one per member):

> This is my Mae Fah Luang University student ID card (Thai). It shows that [Full Name], born [YYYY], is a full-time Year 1 undergraduate student in Software Engineering, valid until [date].

Checklist per member:
- [ ] Born 2002–2008 (University division)
- [ ] Full-time undergraduate (first degree)
- [ ] Scan/photo + English note ready
- [ ] Parent/guardian confirmation if under 21 (done at registration)
