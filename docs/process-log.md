## Entry 4 · 23 พ.ย. · เปลี่ยนทิศทางเป็น Agent-first ("Scout")
**ทำอะไร**
- รู้สึกว่าหน้าเว็บดูเหมือนเว็บรวมงานแข่ง ไม่เหมือน agent → ตอบคำถาม 4 ข้อแล้วได้ทิศทางใหม่:
  - หน้าแรกเป็น "Scout รายงานตัว" ว่าทำอะไรไปแล้ว และมีเรื่องไหนรอให้ตัดสินใจ
  - เรื่องเล็กทำเองได้แต่ undo ได้ (ตารางความอิสระ), ไทม์ไลน์การทำงาน, สั่งด้วยภาษาคน
  - โฟกัส **กิจกรรมมหาลัย + อีเมลเกี่ยวกับงานที่สมัครไว้** ส่วน hackathon เป็นงานเสริม
- ทำ mockup v3 (Agent หน้าหลัก) และเขียน brief ใหม่ทั้งหมด

**ตัดสินใจ / ปัญหา**
- สำรวจเว็บมอ: `mfu.ac.th/news/...` เป็น HTML ธรรมดา ดึงได้ แต่หน้ารวมข่าวมีแค่หัวข้อ ต้องตามลิงก์เข้าไปอ่านทีละข่าว
- ประกาศที่อยู่ใน Facebook / IG / LINE OA ดึงไม่ได้ (ไม่ login แทน user) ต้องบอก user ตรง ๆ
- Gmail กลายเป็นส่วนหลัก → ย้ายขึ้นมาทำเร็วขึ้น

**AI ช่วยอะไร**: Claude ช่วยคิดว่าอะไรทำให้แอป "รู้สึกเป็น agent" และเขียนตารางความอิสระของ Scout

## Entry 6 · 23 พ.ย. · Phase 2: Backend + Database + Eligibility
**ทำอะไร**
- FastAPI + SQLAlchemy (7 ตาราง), เช็กคุณสมบัติด้วยโค้ดล้วน (eligible / not_eligible / unsure), pipeline, ไทม์ไลน์ของ Scout
- **รันรอบสองตอนหน้าไม่เปลี่ยน → เรียก LLM 0 ครั้ง** (เช็ก hash ของ text)
- หน้าที่อ่านแล้วใช้ร่วมกันทุก user: 20 คนดูเว็บมอหน้าเดียวกัน = เรียก LLM ครั้งเดียว

**ตัดสินใจ / ปัญหา**
- eligibility ใช้โค้ด ไม่ใช้ LLM: ฟรี เร็ว ได้คำตอบเดิมทุกครั้ง และถ้าไม่แน่ใจจะตอบ `unsure` ไม่ซ่อนงานทิ้ง
- ถ้าไม่มี API key ระบบเดิมพังทั้งรอบ → แก้ให้บันทึกเป็น error ที่อ่านรู้เรื่อง
- ระบุตัว user ด้วย header `X-User-Id` ชั่วคราว ใช้แค่ตอน dev (Phase 4 เปลี่ยนเป็น Google login)
